# 🛡️ Sentinel AI

### AI-Powered Secure Browsing Assistant

Sentinel AI is an AI-powered Chrome extension designed to identify suspicious websites and protect users against phishing attacks and online scams.

## 🚧 Project Status

Currently Under Development.

## ✨ Core Features

- Real-Time URL Analysis
- Webpage Content Analysis
- AI/ML Phishing Detection
- Explainable AI (XAI)
- Website Trust Score
- Security Alerts
- Cyber Risk Score
- Cyber Twin Profile
- AI Cyber Coach

## 🛠️ Technology Stack

**Frontend**

**Backend**
